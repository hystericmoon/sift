# Store listing

## Name

Sift

## Subtitle (≤ 30 characters)

Clear out join-notice chats

## Short description

Removes chats that hold only a "joined Telegram" notice. Real conversations stay untouched.

## Description

When people in your contacts join Telegram, a chat appears with a single line: "joined Telegram". Over time these pile up between your real conversations.

Sift finds them and lists them for you to review:

- It only lists chats whose one and only message is the join notice. Any chat where someone has written stays off the list.
- Every chat starts selected, and you can untick any you want to keep.
- Before removing a chat, Sift checks it again. If a message arrived since the scan, the chat is skipped and reported.
- Chats are removed for you only. The other person's copy stays, and so do your contacts.
- You get a summary with the number deleted, skipped and failed, with reasons for each.

Everything runs on your computer. Sift has no servers, no accounts, no tracking and no analytics. Your login stays in your system's secure storage (Keychain on macOS, Credential Manager on Windows), and "Log out and remove session" deletes it.

Sift uses the Telegram API and is not affiliated with Telegram.
